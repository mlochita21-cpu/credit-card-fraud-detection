# Credit Card Fraud Detection using Machine Learning

## 📌 Project Description

This project is a Credit Card Fraud Detection system developed using Python.
It analyzes transaction details and calculates a fraud risk score based on
different transaction characteristics.

## 🎯 Objective

The main objective is to identify potentially fraudulent credit card
transactions and help improve transaction security.

## ⚙️ Features

- Transaction analysis
- Fraud risk score calculation
- Detection of unusual transaction times
- Distance-based fraud detection
- Detection of rapid successive transactions
- Multiple transaction detection
- Card-not-present transaction detection
- Fraud reasons and risk analysis
